# 奶我助 · 第一步（软件网页版）

在本地网页上打一句自然语言，列出你还没交的作业。**这一步不碰语音**，
只做两件事：把数据拿到、把流程跑通。

---

## 快速开始

### 1. 生成 Canvas 访问令牌

1. 登录 <https://oc.sjtu.edu.cn>
2. 左上角头像 → **设置**
3. 拉到页面最底部「**已批准的访问许可**」
4. 点「**+ 新建访问许可证**」，用途填 `ddl-check`
5. 点生成 → **立刻复制**（关掉弹窗就看不到了）

> 令牌等同于密码。本项目**只把它存在你自己电脑上**，不上传任何服务器。

### 2. 保存令牌（两种方式任选）

**方式 A：存到本地配置，以后不用再输**

```bash
.venv/bin/python app/cli.py --save-token
```

会写进 `app/config.local.json`（权限自动设为 `600`，仅本人可读）。

**方式 B：临时用环境变量**

```bash
export CANVAS_TOKEN='你复制的令牌'
```

### 3. 跑起来

**命令行版**（最快，先验证数据能不能拿到）

```bash
.venv/bin/python app/cli.py                      # 查全部未交作业
.venv/bin/python app/cli.py "明天有什么要交的"     # 自然语言提问
.venv/bin/python app/cli.py --days 7             # 只看 7 天内
.venv/bin/python app/cli.py --all                # 连没写截止时间的也显示
.venv/bin/python app/cli.py --whoami             # 只验证令牌
```

**本地网页版**

```bash
.venv/bin/python app/server.py
```

然后浏览器打开 <http://127.0.0.1:5173>（会自动尝试打开）。
只监听本机回环地址，不对外网开放。按 `Ctrl+C` 退出。

## 文件说明

| 文件 | 作用 |
|---|---|
| `config.py` | 读取令牌：环境变量优先，其次 `config.local.json` |
| `canvas_client.py` | Canvas REST API 客户端（认证 + **自动翻页**） |
| `ddl_service.py` | 业务逻辑：汇总未交作业、去重、按截止时间排序 |
| `query.py` | 把一句话解析成查询条件（纯规则，不用大模型） |
| `cli.py` | 命令行入口 |
| `server.py` | 本地网页服务（Flask） |
| `static/index.html` | 网页界面（原生 JS，无构建步骤） |
| `test_query.py` | 查询解析的 19 个用例 |
| `test_ddl.py` | 取数/去重/翻页的 15 项验证（用模拟数据） |

## 怎么验证"做对了"

```bash
.venv/bin/python app/test_query.py    # 19 个用例
.venv/bin/python app/test_ddl.py      # 15 项断言
```

`test_ddl.py` 重点覆盖两件**最容易静默出错**的事：

- **翻页**：Canvas 默认每页只返回 10 条，漏翻会少拿作业而**程序不报错**。
  测试用两页的模拟数据验证 `Link` 头被正确跟随。
- **去重**：`/users/self/todo` 和「逐课程查 assignments」会返回同一条作业，
  合并时按 id 去重，并记录它来自哪些渠道。

## 数据来源

三条来源**并列互补**，不是主备关系：

| 来源 | 覆盖范围 | 状态 |
|---|---|---|
| ① Canvas 接口 | 所有在平台上发布的作业 | ✅ 已实现 |
| ② 日历订阅（ICS） | 平台之外的课表与安排 | ⏳ 第二步 |
| ③ 自己录入 | 补前两者拿不到的 | ⏳ 待做 |

目前实现的是 ①，它同时用两条路径取数并合并：

- `/api/v1/users/self/todo`（官方待办，`type=submitting`）
- 遍历课程 → `/api/v1/courses/:id/assignments`（含本人提交状态）

之所以两条都用，是因为官方待办**可能为空或不全**，
逐课程查询能兜住这种情况。每条结果都会标注来源，方便排查。

## 支持的问法

```
我还有哪些作业没交
明天有什么要交的
这周还有什么没交
高数有什么作业
```

**否定句会被当成陈述，不去查数据**：

```
明天没什么要交的     → 不查
我作业都交了         → 不查
没有作业了           → 不查
```

判断不了的输入会明确说「没听懂」，**不会猜一个答案**——
答错会让你误判自己有没有作业。

## 已知限制

- **看不到只在微信群里布置的作业**。接口只能拿到平台上有记录的那些。
  这类要靠第二步的日历订阅或手动录入补。
- **`/users/self/todo` 在各校实例上的行为可能不同**。如果它返回为空，
  程序会自动依赖逐课程查询那条路径（返回结果里会体现来源）。
- 课程简称映射表（`query.py` 里的 `COURSE_ALIASES`）需要按你自己的课表改。
- 令牌**没有过期时间**，建议测完去设置页撤销，需要时再生成。
