奶我助

先把数据来源接上

交我办日历和 Canvas 是两套互不相通的系统，这个 app 取它们的方式也不一样。 第 1 步是必须的，第 2 步选填。

1

交我办日历

必需

课表、活动、讲座这些安排都在交我办里。它没有对外的公开接口， 程序自己读不到，只能借你已经登录的浏览器会话去读。 下面三种做法任选，读到的数据都只送到本机，不经过任何第三方。

不装管理器用「奶我助」自带的扩展

不需要访问任何扩展商店，也不用联网装东西——扩展就在这个项目里。 装完打开日历页就自动同步。

  1. 浏览器地址栏输入 chrome://extensions，打开右上角的开发者模式
  2. 点「加载已解压的扩展程序」，选中这个目录：
    …
  3. 打开 calendar.sjtu.edu.cn/ui/calendar，右下角会出现「奶我助」面板

扩展就在同一台机器上，第 2 步直接选目录即可。 想把它放到别处或发给别人：下载 zip，解压后再选。

已经装了管理器用 Tampermonkey / Violentmonkey
  1. 没装的话先装一个
    Edge 商店装 Tampermonkey Edge 商店装 Violentmonkey

    这两个链接走微软的商店，国内一般能直连。两个装一个就行，作用一样。
    Chrome 网上应用店国内打不开；那里面下的 .crx 文件 Chrome 也不让装 （会报 CRX_REQUIRED_PROOF_MISSING），所以别去找离线包。
    用 Firefox / Safari 的话去官网按浏览器选： Tampermonkey 官网 · Violentmonkey 官网

  2. 再装这个同步脚本
    安装自动同步脚本

    装好后打开 calendar.sjtu.edu.cn/ui/calendar， 右下角会出现「奶我助」小面板，它自己读数据、自己推给本机。
    如果点上面那个按钮只是打开一段代码文本，说明管理器还没装好—— 回去装好，刷新这一页再点一次。

什么都不装每次手动跑一遍，导出文件再拖进来

在这张页面上按 F12 → Console，粘贴脚本回车，会下载一个 JSON 文件， 把它拖到下面的虚线框里。

把导出脚本生成的 JSON 拖到这里，或
怎么拿到这个 JSON 文件？（三步）
  1. 浏览器登录 calendar.sjtu.edu.cn/ui/calendar
  2. 在这张页面上按 F12 → Console，粘贴刚复制的脚本，回车
  3. 会下载一个 sjtu-calendar-<时间戳>.json，拖到上面的虚线框里
脚本在你自己的页面里运行，借你已经登录的会话读数据。 它不登录、不读 cookie、不保存密码，也不把数据发给任何第三方。

Canvas 访问令牌

选填 · 填了才能看到作业截止

作业和截止在 oc.sjtu.edu.cn 上。它有公开接口，生成一个访问令牌就能读。 不填也能用，只是「ddl」那一格一直是空的。

1. 登录 oc.sjtu.edu.cn → 左上角头像 → 设置
2. 拉到页面最底部「已批准的访问许可」→「+ 新建访问许可证」
3. 用途随便填（如 naiwozhu）→ 生成 → 立刻复制（关掉弹窗就看不到了）
需要先导入一份交我办日历 JSON
