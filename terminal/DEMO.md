## 2. 演示分镜（约 4 分钟）

**说话节奏很重要**：先说唤醒词，**听到应答再问问题**，不要一口气说完。
应答音那段时间麦克风不录音（角色原声有 2.66 秒），连着说会把中间的半句吃掉
（要一口气说就 `ACK=0`）。

| 你说 | 它说 | 讲解点 |
|---|---|---|
| **「奶龙你好」** | 我在。 | ⭐ **最抓人的 3 秒**：唤醒 + 应答。强调这是**纯离线**的 |
| 我还有哪些作业没交 | 你有三个作业没交。最急的是英语课期末作文，还有六小时。 | 报数量 + 最急的，不念整张表——语音不是列表 |
| 我明天有什么安排 | 有两个安排。最近的是高等数学，明天上午八点，在东上院415。 | 时间、地点都能给 |
| 这周有什么任务 | 你有三个作业没交。最急的是英语课期末作文，还有六小时。 | 时间窗过滤 |
| 高数有什么作业 | 你有一个作业没交。最急的是高数第五章习题，还有一天。 | 按课程筛 |
| **把明天第一节改到下午两点** | 把明天上午八点的高等数学改到下午两点，对吗？ →「对」→ 改好了。只在本机生效；交我办里的课表还是原样。 | ⭐ **先复述再写**，而且**只改本机**，不碰交我办 |
| **删掉明天的学生会例会** | 要删掉……吗？ →「对」→ 好，删掉了。 | ⭐ 删之前一定问一遍；想反悔就说「撤销」 |
| 今天天气怎么样 | 这个我还不太会，你换个说法试试。 | ⭐ **它不会瞎编**——听不懂就说听不懂 |

### 收尾一招：证明两端是同一份数据

电脑浏览器打开 <http://127.0.0.1:5173>，网页上删掉一条作业，然后**再问一次**「我还有哪些作业没交」——数字跟着变。

这一步比任何架构图都有说服力：**终端没有自己的数据库，它就是个听和说的壳。**

### 到点提醒：不用问，它自己开口

提醒按时间窗触发（早间 8 点 / 晚间 10 点 / 日程前一小时），现场等不到那个点，
所以准备一条命令直接把内容念出来：

```bash
python assistant.py --remind --preview     # 三个位都算一遍，不管现在几点
```

讲解点：**判定在电脑端，念的时机在终端**——电脑端回答「现在该念什么」，
终端只在空闲时问、按 `remind_id` 去重。它不会在你说到一半时插话，
也不会因为没到点就念一句「暂时没有提醒」。

## 3. 被问到怎么说

**「音色怎么不是奶龙？」**
> 音色替换是最后一步，素材管线已经通了：目前这 282 条片段是占位音色生成的，
> 换成奶龙引擎只要重跑一条命令 `python gen_voice.py --from-api --provider cmd`，
> 格式完全一样，识别和播报的代码一行都不用改。

**「唤醒词为什么不太准？」**
> `奶龙` 这两个字不在 Vosk 中文小模型的词表里，模型永远拼不出它们，只会输出同音词
> （实测："奶农你觉得"、"哪笼鸟"、"那句你好"）。所以除了别名列表，还加了一条
> 同音字族正则 `[奶哪那乃奈][龙笼隆荣农牛]`，并且把识别成"您"的按"你"处理——
> 就是这一个字，之前导致唤醒一次都没触发。

**「为什么要用大模型？规则不行吗？」**
> 规则做筛选，大模型只做**参数抽取**。语音会把"课"听成"可"，按关键词判类型就错了
> （实测："我今天有什么可"会把作业混进日程结果）。终端先纠字、直接给 `kind`，
> 规则那层就只负责筛选，不负责猜。而且模型只输出 `kind/range/course`，
> 数据一律来自电脑端，它编不出一条假作业。

**「登录状态怎么办？」**
> 交我办的会话在电脑浏览器里，终端拿到的永远是快照——这是架构决定的，不是没做到。
> 所以播报日程时如果快照超过 24 小时没更新，它会主动补一句"课表已经两天没更新了"。
> 作业那块不受影响，Canvas 用令牌，没有会话可掉。

## 4. 翻车预案

| 现象 | 立刻怎么办 |
|---|---|
| 喊了唤醒词没反应 | 直接改用 `python assistant.py --say "我还有哪些作业没交"`，效果一样只是不喊唤醒词 |
| 它说「网络不太通畅」 | 模型接口超时/限流，**原话再说一遍**就行（代码里已经会自动重试一次） |
| 教室太吵、一直被当成没说话 | 加 `--denoise` 重跑；还不行就 `$env:VAD_THRESHOLD="0.01"` |
| 电脑端连不上 | 看终端 A 的窗口有没有报错；确认是 `127.0.0.1:5173` |
| 喇叭没声 | 先跑 `--check` 看最后一项「喇叭」，按设备列表把 `OUT_DEVICE` 指对 |

**别在现场做的事**：改代码、重启服务、临时装依赖。演示只要两个窗口。
