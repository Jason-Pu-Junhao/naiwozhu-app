# 来源与上游同步

## 这个目录从哪来

`terminal/` 是组内语音终端仓库的副本：

| 项 | 值 |
|---|---|
| 上游 | https://github.com/walkerljy/naiwozhu-terminal |
| 作者 | 刘嘉远（`@walkerljy`），见 `LICENSE`（保留所有权利，仅组内课程项目使用） |
| 同步的提交 | `ca64ddf`「接电脑端新接口：条目改删隐藏 + 到点提醒」 |
| 同步日期 | 2026-11-12 |

放进同一个仓库，是为了**一个 clone 就能把整套跑起来**：
`app/` 是电脑端（数据与业务），`terminal/` 是语音终端（听与说），
两者的接口契约见 `terminal/INTEGRATION.md` 与仓库根的 `API.md`。

## 和上游的差异（只有两处）

1. `README.md` 顶部加了一段来源说明；文件清单里删掉了 `edit_pptx.py` 那一行。
2. 上游根目录的 `presentation-updated.pptx`（400 KB，改过的旧版答辩 PPT）与
   `edit_pptx.py`（改那份 PPT 的脚本）**没有带过来**：答辩 PPT 以本仓库外面的
   `assets/文档/` 那一份为准，避免仓库里出现两个版本的 PPT。

代码本身没有改动一个字符。

## 上游更新了怎么同步

```bash
git clone git@github.com:walkerljy/naiwozhu-terminal.git /tmp/nt
cd /path/to/naiwozhu-app

# 看上游新提交
git -C /tmp/nt log --oneline

# 只同步代码文件（别把 models/、resources/voice/*.wav、local_secrets.py 带进来）
for f in asr_bench.py assistant.py audio.py backend.py cloud_asr.py config.py \
         DEMO.md download_model.py gen_voice.py INTEGRATION.md llm.py \
         local_secrets.example.py requirements.txt stt.py tts.py; do
  cp -p /tmp/nt/$f terminal/
done
cp -p /tmp/nt/README.md terminal/README.md      # 记得把上面那段来源说明和 edit_pptx 那行再处理一次
```

同步完跑一遍链路冒烟（不需要麦克风与密钥）：

```bash
bash app/run.sh --host 0.0.0.0 --access-key smoke-key &   # 或另开一个终端
BACKEND_URL=http://127.0.0.1:5173 .venv/bin/python tools/smoke_link.py
```

没报错就说明两边的接口契约还对得上；终端里的唤醒、识别、播报要硬件和密钥，
不在这个脚本的范围内。
